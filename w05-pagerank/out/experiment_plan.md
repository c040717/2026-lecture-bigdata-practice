# 5주차 실험 계획

- 그래프 생성기는 제공된 `bench.build()`를 사용하고 seed는 246으로 고정한다. `bench.py`와 DenseMatrix는 수정하지 않는다.
- 노드 1,200개와 12,000개에서 β를 0.5, 0.7, 0.85, 0.95, 0.99로 바꾼다. 허용 오차는 L1 기준 1e-10, 반복 상한은 5,000회로 둔다.
- 노드 1,200개, β=0.85에서 허용 오차를 1e-3부터 1e-10까지 한 자리씩 줄인다. 각 조건은 한 번 측정하고 1e-10 결과는 앞 실험의 같은 조건을 사용한다.
- 실행 전 예상: 노드가 10배 늘면 처리할 간선도 많아져 시간은 늘 것이다. 반복 횟수는 노드 수보다 β와 그래프 구조, 허용 오차의 영향을 받아 10배까지 늘지는 않을 것으로 예상한다.
- CPU와 RAM은 실행 환경에서 읽는다. 측정 중에는 Whale 브라우저, 대화형 데스크톱 프로그램, Windows Defender와 일반 백그라운드 작업을 종료하지 않는다.
- 그래프 생성과 정렬을 제외한 `pagerank()`의 실행 시간만 잰다. 종료 후 한 번 더 갱신해 L1 잔차를 확인하고 각 조건의 top-10 순서를 비교한다.
- 희소 구현은 수정하지 않은 `bench.py --yours`로 비교한다. `memory_floats()`는 저장하는 실수의 개수이며 실제 프로세스의 RAM 사용량과는 구분한다.
