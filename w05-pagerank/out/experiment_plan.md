# 5주차 측정 계획 — 실행 전 예상

- 생성기 `bench.build()`, seed 246을 그대로 사용한다. `bench.py`는 수정하지 않는다.
- β는 0.5, 0.7, 0.85, 0.95, 0.99로 바꾸고 노드 수 1,200과 20,000에서 같은 실험을 수행한다. 기본 L1 허용 오차는 1e-10이다.
- β=0.85, 노드 1,200에서 허용 오차를 1e-3부터 1e-10까지 한 자리씩 줄인다. 반복 상한은 5,000으로 두고 실제 수렴 여부도 확인한다.
- **A4 실행 전 예상:** 그래프가 커지면 매 반복에 처리하는 노드·간선이 늘어 실행 시간은 늘 것이다. 반복 횟수는 크기에 직접 비례하지 않고 β, 그래프 구조, 허용 오차에 좌우될 것으로 예상한다. 크기에 따라 생성된 그래프의 구조도 달라지므로 반복 횟수가 완전히 같다고 예상하지는 않는다.
- 측정은 같은 Windows 실행 환경에서 순차로 수행한다. CPU와 설치 RAM은 실행 시 읽고 대화형 프로그램이 함께 실행된 상태로 측정한다. 다른 백그라운드 작업까지 모두 종료한 전용 벤치마크 환경은 아니다.
- Task 3은 수정하지 않은 `bench.py --yours`의 출력으로 비교하며, 메모리는 실제 프로세스 RAM이 아니라 과제의 `memory_floats()` 기준임을 구분한다.
