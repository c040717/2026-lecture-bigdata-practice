# PCY의 카운터와 메모리

## 기본 크기에서의 비교

버킷은 1,048,576개로 잡았다. 정수 배열 비용을 4 MiB로 제한하면서 작은 배열보다 충돌을 줄이기 위해서다. 기본 데이터에서 쌍 카운터는 820,259→13,017개로 98.4% 줄었다. 정답은 6,397개로 같았고, 별도 비교에서는 각 쌍의 빈도까지 사전 전체가 일치했다.

버킷은 4바이트 정수 배열이므로 본체가 4,194,304바이트다. 비트맵은 131,072바이트(0.125 MiB)이고, 변환 중에는 둘이 함께 있어 본체만 4,325,376바이트(4.125 MiB)다. 항목 번호 사전, 리스트, 집합과 객체 관리 비용도 추가된다. 2패스를 시작하기 전에 정수 배열을 삭제하고 비트맵만 남겼다.

추적한 추가 할당 최대값은 102.29→4.68 MB로 95.4% 감소했다. 카운터 감소율과 실제 메모리 감소율은 같지 않다. 결과로 옮길 때 후보를 하나씩 꺼내지만, 비워진 사전의 내부 공간이 바로 줄어든다고 가정하지 않고 전체 할당 최대값으로 비교했다.

`bench.py`는 수정하지 않았다. `bench.txt`에서는 baseline 1.65초, PCY 3.06초로 PCY가 더 느렸다. 1패스에서 모든 쌍을 해싱하고 2패스에서도 버킷을 검사하므로, 이번 구현의 이점은 메모리이지 실행 시간은 아니었다.

## 어느 크기부터 이득인가

동일하게 생성한 20,000개 바구니의 앞부분을 사용했다. support는 절대 개수 50, 버킷은 1,048,576개로 고정했다. 모든 행에서 정답과 빈도까지 같았다.

| 바구니 수 | A-Priori 카운터 | PCY 카운터 | A-Priori 추가 메모리(MB) | PCY 추가 메모리(MB) |
|---:|---:|---:|---:|---:|
| 500 | 136 | 12 | 0.11 | 4.53 |
| 1,000 | 1,078 | 59 | 0.19 | 4.54 |
| 2,000 | 6,228 | 181 | 0.83 | 4.55 |
| 4,000 | 30,407 | 588 | 3.24 | 4.55 |
| 8,000 | 133,872 | 1,942 | 13.28 | 4.58 |
| 20,000 | 820,259 | 13,017 | 102.29 | 4.68 |

측정한 크기 중 8,000개에서 처음 PCY가 더 적게 썼고, 교차점은 대략 4,000~8,000개 사이였다. 작은 데이터에서는 후보가 적어 고정 버킷 배열이 오히려 손해였다. 이 구간은 이번 support, 항목 분포, 해시와 버킷 수에서의 결과이며, 보편적인 바구니 수 기준은 아니다.

## 버킷 배열을 줄이면

| 버킷 수 | 배열 본체(bytes) | 비트맵(bytes) | 빈발 버킷 | 쌍 카운터 | 추가 메모리(MB) | 정답 수 |
|---:|---:|---:|---:|---:|---:|---:|
| 1,048,576 | 4,194,304 | 131,072 | 6,940 | 13,017 | 4.68 | 6,397 |
| 65,536 | 262,144 | 8,192 | 21,545 | 300,587 | 27.62 | 6,397 |
| 4,096 | 16,384 | 512 | 4,096 | 820,259 | 102.35 | 6,397 |

65,536개로 줄이면 배열 자체는 작아졌지만 충돌 때문에 통과하는 후보가 많아져 추가 메모리가 27.62 MB로 커졌다. 4,096개에서는 모든 버킷이 빈발해 필터가 아무 쌍도 제거하지 못했고 카운터가 baseline과 같아졌다. 세 경우 모두 정답의 쌍과 빈도는 같았다.

## 측정 범위와 재실행

메모리는 `tracemalloc`으로 각 `run()`의 추가 할당 최대값을 쟀다. 결과 사전과 배열·비트맵은 포함하고, 미리 생성된 입력이나 이전 비교 결과는 제외한다. 프로세스 전체 RAM 비교가 아니다. 각 실행 전에 가비지 컬렉션을 했으며, 이 별도 실험의 원본 수치는 `pcy_memory.json`에 있다. MB는 1,000,000바이트다.

기존 `out/pcy_memory.json`을 별도 보관한 뒤 다음을 실행한다. 이 측정은 추적 비용을 포함하므로 실행 시간이 `bench.py`보다 길다.

```powershell
python measure_pcy.py
python bench.py --yours
```
